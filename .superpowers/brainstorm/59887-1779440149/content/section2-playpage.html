第二节：播放页 SSR 内容拆分

确保搜索引擎可抓取 H1、简介、元信息

现状

play/[id]/page.tsx (Server)
└─ PlayerShell (Client) ← 全部内容在此
   ├─ H1 (客户端渲染)
   ├─ Synopsis (客户端渲染)
   ├─ 导演/年份/评分 (客户端渲染)
   ├─ 选集列表 (客户端渲染)
   └─ Video播放器
   搜索引擎看到的是空的 HTML

改造后

play/[id]/page.tsx (Server) ← 内容在此渲染
├─ Breadcrumb (Server)
├─ H1 + 年份+导演+评分 (Server)
├─ Synopsis (Server)
├─ JSON-LD (Server)
└─ PlayerShell (Client) ← 只留播放+选集
   ├─ Video播放器
   └─ 选集切换
   搜索引擎获得完整的 SSR HTML

具体拆法

  • PlayPage (page.tsx): 在服务端 fetch anime detail，将 H1/synopsis/元信息 直接渲染到 HTML 中
  • PlayerShell: 从 AnimeDetail 改为只接收 {play_sources, poster, title, _id} 等播放器必需字段
  • VideoInfo sidebar: 原有的侧边栏海报/评分/分类可留在 PlayerShell 中（不影响 SEO），也可部分提取到 Server
  • 核心原则：「搜索引擎需要看到的内容」在服务端渲染，「用户交互」留在客户端
