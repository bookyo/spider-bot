第五节：内链优化 + 相关推荐

构建站点内部链接网络，提升爬虫效率和页面权重传递

Footer 内链网络

  • 所有分类链接 → 分类页
  • 近年份链接 → 年份页
  • 每个链接都是可索引的 URL
  • Footer 在所有页面出现，天然形成链接矩阵

播放页相关推荐

  • 同分类动漫 4-6 个
  • 数据从 API 的相近筛选获取
  • Server Component，SSR 渲染
  • AnimeCard 组件复用

具体实现

  • Footer: Server Component，从 getAnimeFilters() 获取分类和年份列表，渲染为链接网格
  • 相关推荐 RelatedAnime: 新增 components/related-anime.tsx，Server Component，用当前动漫的 genres/year 构造 API 查询，返回同类型作品卡片
  • 首页最新列表：已有，保持
  • 所有链接使用 <Link> (next/link) 确保客户端导航
