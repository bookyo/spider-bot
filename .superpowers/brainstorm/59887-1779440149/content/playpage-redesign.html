核心改动

① 恢复海报 + meta 侧边栏（SSR 渲染）

海报、评分、导演、分类链接不放在 Client 的 PlayerShell 中，在 page.tsx 的 Server Component 中渲染。grid 恢复 xl:grid-cols-[minmax(0,1fr)_340px] 布局。

② 信息层级重排：视频 → 侧边栏 → H1 → 剧集

桌面：视频 + 侧边栏在一行，H1/synopsis 在下方占据整行。
移动：视频全宽 → 海报横向小图 + meta → H1 → 剧集。

③ 首页 hero 移动端体量压缩

手机端 8xl 标题 → 5xl，统计卡片 2×2 改为横向滚动，减少首屏垂直高度。

移动端 vs 桌面端布局

区域 桌面 (≥1280px) 移动 (<768px)
视频 + 侧边栏 grid 并排 视频全宽，海报横条在下
H1 + synopsis 视频下方整行 视频下方整行
剧集列表 全宽 全宽
相关推荐 全宽，4列 全宽，2列
