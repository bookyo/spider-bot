第三节：结构化数据 JSON-LD

Rich Results 的核心 — 让 Google 理解页面内容

1. WebSite + SearchAction (Layout 层)

全局注入，所有页面都有。让 SERP 显示站点搜索框 (Sitelinks Search Box)。 

{"@context":"https://schema.org",
 "@type":"WebSite","url":"https://vbot.reelbit.cc",
 "potentialAction":{"@type":"SearchAction","target":{"@type":"EntryPoint",
   "urlTemplate":"https://vbot.reelbit.cc/?keyword={search_term_string}"},
   "query-input":"required name=search_term_string"}}

2. BreadcrumbList (所有页面)

与 breadcrumb 组件同步生成，确保视觉 breadcrumb 和 JSON-LD 一致。

3. VideoObject (播放页)

最重要的结构化数据。让 Google 展示视频预览和播放按钮。 

{"@context":"https://schema.org","@type":"VideoObject",
 "name":"{anime.title}","description":"{anime.synopsis}",
 "thumbnailUrl":"{poster}","contentUrl":"{firstEpisode.url}",
 "duration":"{calculated}","datePublished":"{anime.year}",
 "author":"{anime.director}","genre":["{genres}"]}

4. ItemList (首页/分类页/年份页)

列表页使用 ItemList + ListItem 标记，让 Google 理解页面是一个内容集合。 

{"@context":"https://schema.org","@type":"ItemList",
 "name":"{title}","itemListElement":[
   {"@type":"ListItem","position":1,"url":"/play/{id1}"},
   {"@type":"ListItem","position":2,"url":"/play/{id2}"}]}

实现方式

  • 新增 lib/json-ld.ts — 纯函数，生成各类型的 JSON-LD 对象
  • Layout 级：<script type="application/ld+json" dangerouslySetInnerHTML /> 注入 WebSite
  • 各页面 inline 注入 BreadcrumbList + 页面特有 JSON-LD
  • JSON 字符串先 JSON.stringify 再插入，避免 XSS
