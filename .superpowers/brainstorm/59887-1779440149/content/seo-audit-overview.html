🎯 SEO Audit: 当前前端状态总览

基于全面代码审查发现的 SEO 缺口

已覆盖的部分 ✅

  • SSR 页面架构 (Next.js App Router)
  • 基础 Metadata / OpenGraph / Twitter Cards
  • Robots.txt + Sitemap.xml
  • 语言声明 zh-CN
  • 规范的 generateMetadata 动态 meta
  • ISR (revalidate) 策略

缺失的关键部分 ❌

  • 结构化数据 (JSON-LD) — 无 VideoObject、BreadcrumbList、WebSite 标记
  • 语义 HTML 骨架 — 无 <header>/<nav>/<footer>
  • 面包屑导航 — 所有页面都没有
  • 播放页内容在客户端渲染 — H1、简介、剧集列表在 Client Component 中
  • 无网站导航栏 — 用户无法在页面间跳转
  • 无「相关推荐」内链 — 内部连接矩阵缺失

技术深度问题 🔧

  • Sitemap 只取 200 条 → 需要分页或 sitemap index
  • 使用原生 <img> 而非 next/image → 无自动优化
  • 缺少 next.config.ts 的 images / headers 配置
  • 过滤栏中 /genre/[genre]/year/[year] 路径无对应路由
  • 缺少成功搜索页面
  • 无 About / 关于页面（信任信号）
